What does the AI actually read?

Text only. When you summarize a chat or build a report, WA Turbo extracts the message text inside the window you chose and sends nothing else. Images, voice notes, documents, stickers and location pins are never part of the context the model receives.

Images still show up in the chat. The limit is on what leaves your Mac for summarizing, not on what the app displays — you read the conversation exactly as WhatsApp renders it, photos included. A summary simply will not describe what is in a picture, and an attachment can never be the source of an action item.

So a screenshot in a thread is invisible to the summary?

Yes. If a bank PIC sends the callback spec as a screenshot instead of typing it, the summary sees the surrounding messages but not the spec itself. The BCA UAT thread has one exactly like this — it renders in the chat and is tagged “not read by AI”. For anything that must reach a report, ask for it as text, or type the key line into the thread yourself.

Where do my messages go?

Chats stay on this Mac. Only the text you select for a summary or report is sent, to Anthropic, using the API key you entered — there is no WA Turbo server in between. Phone numbers are swapped for stable aliases before the request leaves the Mac, so the model never sees the raw numbers. Generated reports are written locally and are not synced anywhere.

Does opening a chat clear an open loop?

No, and that is deliberate. Read state and reply debt are separate: a loop closes when you mark it answered or confirmed, never because you looked at the thread. That is the whole reason a chat you read on Monday still shows up in SUM UP! on Friday.

Can one login see another login's chats?

No. Each platform login keeps its own session and its own inbox, and there is no merged chat list. SUM UP! is the only place they are counted together, and every row there links back to the chat inside its own login.

What restarts the waiting clock?

A nudge. Total waiting time keeps counting from the original question, but the SLA clock restarts from your last follow-up — so "asked 4 days ago, chased an hour ago" and "asked 4 days ago, never chased" do not look the same.
